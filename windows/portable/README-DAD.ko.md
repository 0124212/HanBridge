# 중국어 번역기 (HanBridge 휴대용) — 3단계

설치 없음. 관리자 권한 불필요.

## 사용법

1. **압축 풀기** — 받은 zip을 짧은 경로에 풉니다. 예: `C:\hanbridge`
   (경로가 100자를 넘으면 실행이 안 됩니다. 바탕화면 깊은 폴더는 피하세요.)
2. **차단 해제** — zip에서 풀고 나면 `Translate-CN.bat`에 우클릭 →
   속성 → 하단 **차단 해제(Unblock)** 체크 → 확인.
   (SmartScreen 경고가 뜨면 "추가 정보" → "실행"을 누르세요.)
3. **더블클릭** — `Translate-CN.bat`을 더블클릭하면 번역기 창이 열립니다.
   PDF를 창에 넣거나, PDF 파일을 `Translate-CN.bat` 아이콘에 **드래그**해도 됩니다.

## 결과물

- 번역된 파일은 **원본 파일 옆 `translated` 폴더**에 생깁니다.
  예: `보고서.pdf` → `translated\보고서-한文版.pdf` + 한글/중국어 대조 PDF.
- 스캔 PDF(이미지 PDF)도 자동으로 인식해서 번역합니다 (중국어 인식 포함).

## 알아둘 것

- **인터넷 필요** — 번역은 무료 translatepy로 하며 인터넷이 있어야 합니다.
- WorkBuddy 토큰이 있으면 자동으로 그걸 먼저 씁니다 (없으면 무료 방식).
- 목표 언어는 기본 한국어입니다.
