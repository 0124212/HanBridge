# HanBridge 휴대용 — 3단계

1. **압축 풀기** — 받은 zip을 아무 곳에나 풉니다. 예: `C:\hanbridge` (짧을수록 좋음)
2. **더블클릭** — `HanBridge.bat`을 더블클릭하면 번역기 창이 열립니다.
3. **드래그** — 중국어 PDF를 `HanBridge.bat` 아이콘에 드래그하면 원본 옆 `translated` 폴더에 저장됩니다.

차단 해제 — `HanBridge.bat` 우클릭 → 속성 → 하단 **차단 해제** 체크. 파란 SmartScreen이 뜨면 **추가 정보** → **실행**.
