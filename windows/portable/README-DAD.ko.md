# HanBridge 휴대용 — 3단계 (키보드 입력 없음)

터미널을 열 필요가 없습니다. 마우스로만 하면 됩니다.

1. **압축 풀기** — 받은 zip을 짧은 경로에 풉니다. 예: `C:\hanbridge`
   (경로가 100자를 넘으면 실행이 안 됩니다. 바탕화면 깊은 폴더는 피하세요.)
2. **차단 해제** — `HanBridge.bat`에 우클릭 →
   속성 → 하단 **차단 해제(Unblock)** 체크 → 확인.
   파란색 SmartScreen 창이 뜨면 **추가 정보** → **실행**을 누르세요. (바이러스 아님)
3. **더블클릭** — `HanBridge.bat`을 더블클릭하면 번역기 창이 열립니다.
   중국어 PDF 파일을 `HanBridge.bat` 아이콘에 **드래그**해도 됩니다.

## 결과물

- 번역된 파일은 **원본 파일 옆 `translated` 폴더**에 생깁니다.
  예: `보고서.pdf` → `translated\보고서-한文版.pdf` + 한글/중국어 대조 PDF.
- 번역이 끝나면 결과 폴더가 자동으로 열립니다.
- 스캔 PDF(이미지 PDF)도 자동으로 인식해서 번역합니다 (중국어 인식 포함).

## 알아둘 것

- **인터넷 필요** — 번역은 무료 방식이라 인터넷이 있어야 합니다.
- 목표 언어는 기본 한국어입니다. 아무것도 고르지 마세요.

## 설치판 화면 미리보기 (보이는 화면, 고를 것 없음)

`setup-dad.bat`으로 설치하면 아래 6개 화면이 순서대로 보입니다.
아무것도 고르지 마세요. 가만히 계시면 자동으로 넘어갑니다.

1. [1/6] 파이썬 확인 — 컴퓨터를 확인하고 있어요
2. [2/6] 기본 준비 — 준비하고 있어요
3. [3/6] 설치 중 (몇 분) — 자동으로 설치 중이에요 (몇 분 걸려요)
4. [4/6] 기본 설정 — 기본 설정을 만들고 있어요
5. [5/6] 바탕화면 바로가기 — 바탕화면 아이콘을 만들고 있어요
6. [6/6] 마무리 확인 — 마지막으로 확인하고 있어요

끝나면 "완료! 바탕화면 HanBridge 아이콘을 쓰세요"가 보입니다.
빨간색 한 줄 + **다시 시도**가 보이면 그 버튼 하나만 누르세요.
